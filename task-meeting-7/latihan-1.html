Apa itu Bootstrap?

Bootstrap adalah framework untuk mendesain website dengan cara yang mudah. Dengan Bootstrap, kita dapat membuat layout halaman, tabel, tombol, form, navigasi, dan komponen lainnya hanya dengan memanggil class CSS yang sudah disediakan. Halaman ini sendiri dibuat menggunakan sistem grid Bootstrap: sidebar memakai col-md-3 dan konten memakai col-md-9.
